**Belum punya lingkungan Azure demo?** Tetap mulai dari panduan 1-3. Data contoh,
penjelasan, dan pemeriksaan lokal terbatas tidak membutuhkan provisioning cloud.
Jangan langsung menjalankan script deployment atau tes berlabel `live`.
