Tiga opsi migrasi workflow Foundry

Pilih mapping ke Python MAF, workflow YAML MAF, atau Logic Apps. Yang pindah aturan alurnya; agent tetap bekerja di Foundry.

Microsoft Agent Framework (MAF) adalah SDK untuk aplikasi. Dua opsi MAF sama-sama memakai Python; bedanya ada pada cara alur dibuat.

Persiapan

Bedanya ada di yang kamu siapkan dan siapa yang menjalankan

MAF mapping ke kode: Python membangun graph

Compiler demo membaca YAML Foundry dan memetakan langkah yang didukung. Kode Python membaca mapping, lalu membuat executor dan kondisi lewat WorkflowBuilder.

Pilih saat logika perlu mudah ditinjau dan diuji di kode. Compiler ini terbatas pada subset demo; tidak otomatis mengubah semua workflow Foundry.

Lihat mapping yang dibaca dan kode yang menjalankannya

Mapping runtime (JSON) menyimpan route dan branch. Kode graph Python memasang kondisi setiap branch.

YAML di targets/maf menyajikan hasil mapping. Itu bukan input untuk loader YAML pada jalur ini.

MAF pakai workflow: loader membaca langkah dari YAML

Alur tetap sebagai file YAML yang kompatibel. Python menyiapkan agent yang dipakai, lalu WorkflowFactory membuat graph langsung dari definisi.

Pilih saat kamu ingin aturan tetap terbaca sebagai YAML. Demo ini jalur terpisah dari baseline kode; file dan versi SDK harus cocok.

Lihat YAML yang dimuat dan loader Python

File workflow YAML berisi langkah dan kondisi. WorkflowFile.create memasangkan definisi dengan agent yang sudah disiapkan.

YAML dibaca saat startup UI demo. Buat snapshot baru lewat restart kalau file berubah. Batas hash di repo adalah penjagaan demo, bukan syarat umum loader.

Logic Apps: Azure menjalankan workflow native

Definisi dipetakan ke action Logic Apps, seperti Request, Switch, dan HTTP. Azure menjalankan alurnya; Python di UI demo hanya meneruskan request dan membaca run.

Pilih saat tim perlu melihat node, Parameters, dan Run history di portal. Siapkan workflow, autentikasi, dan izin sebelum uji live.

Lihat definisi workflow dan video Designer

Definisi WDL (JSON) berisi action dan urutannya. Node Switch membaca body('router_decision')?['route']. Normalizer Python memeriksa bukti; ia tidak memilih cabang.

Video Designer: kotak node, Parameters, dan hasil MCP.

Yang tidak otomatis ikut pindah: agent, model, koneksi tool, izin, dan data. Menyiapkannya berbeda dari menjalankan satu request.

Cek perilaku

Pakai input yang sama untuk membandingkan hasil

Kirim contoh ini hanya jika lingkungan demo sudah siap dan kamu berizin. Membuka halaman ini tidak menjalankan tes atau menambah biaya cloud.

{"question":"Show work orders for equipment TRK001."}

Kalau cabang atau sumber berbeda, telusuri input dan output tiap langkah. Tanda hijau pada satu action belum membuktikan hasilnya benar.
